Does the upstream aligner's setting hide pks reads from extraction?

Answers E1, V3, V6 · simulation on synthetic reads and public references, plus a pooled real-data pilot · commit b8d3f60 · 2026-09-30

Real report from 30 Sep 2026, cleaned for sharing: cohorts, aligner settings and genes anonymised; every number replaced with a placeholder; internal pipelines and documentation sources removed.
Answer. Yes. One alignment setting used upstream by Cohort A hides about half of genuine pks reads, because the aligner counts weak chance matches to the human genome as "mapped". Cohort B, aligned with the default, loses almost none. Also extracting the reads the default setting would have left unmapped recovers nearly all of them, with no human reads getting through.

What I found

1. The strict setting alone explains the loss

Changing only the score setting on the same reads reproduces the whole difference, on both references. Longer reads lose more, because a chance match is easier to find in a longer read.

Read lengthSettingInjected pks reads left unmapped

2. The proposed extraction rule recovers almost everything

Keeping unmapped reads plus primary mapped reads scoring below the default threshold brings every setup to about the same level. No simulated human read passes host removal under the new rule.

3. On real samples, tumours gain evidence and normals gain none

Pooled over the pilot: tumours move up, never down; matched normals do not change.

What this doesn't show, and what's next

  • Limit: The pilot was chosen near tier thresholds, so its rate of new positives is not the cohort rate.
  • Limit: Simulated human reads are cleaner than real ones; the matched normals are the real specificity test.
  • Limit: The loss is uneven across genes, so gene-level patterns in earlier results are skewed, not just totals.
  • Next: Run the full cohort, tumours and matched normals, and report tier changes cohort-wide; then WES.
  • Next: Build the rule into extraction, applied only when the input header shows the affected aligner.
